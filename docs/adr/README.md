# Architecture decision records

Short records of significant design decisions in excanon: the context, the decision, and its consequences. Each ADR lands in the same pull request as the change it describes. ADRs are never edited after merging. A later ADR supersedes an earlier one and links back to it.

## Format

File name: `NNNN-short-title.md`, numbered in order.

```markdown
# NNNN. Title

- Status: accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
What forced a decision, and the constraints.

## Decision
What was decided, in one or two paragraphs.

## Alternatives
What else was considered, and why not.

## Consequences
What becomes easier, what becomes harder, and what users must know.
```
